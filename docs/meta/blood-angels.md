# Blood Angels — jump-melee alpha (Liberator Assault Group / Angelic Host) (11E, verified 2026-07-26)

Both current 5-0-0 BA lists are the same idea: a **jump-pack melee ALPHA** with best-in-game
delivery. Stats live-verified vs BSData/wh40k-11e (`ba11.json` + `ba_fp.txt`). This is the
purest "melee into the fight phase" archetype — and the one Sisters answer BETTER than Knights.

## The list & tapestry
**Liberator Assault Group — "Red Thirst": +2 Strength / +1 Attack ON THE CHARGE, army-wide.**
That turns every melee unit up a tier the moment it connects:
- **Death Company** (fists **S10** on the charge) + **Lemartes** (Lethal Hits + **−1 Damage** to
  the unit).
- **Sanguinary Guard** blades **S8 AP-3** on the charge; Dev-Wound hammers in the mix.
- One DC + Lemartes charge = **~15-18 into a Questoris** in the no-melee-invuln fight phase.

**The Angelic Host — "Upon Wings of Fire": re-drop.** Same jump core with a redeploy/re-drop
engine. Delivery is the best in the game: **M12" + Deep Strike + re-roll charge + Angelic-Host
re-drop** — the alpha lands where it wants, when it wants.

## Anti-Knight threats
- **Melee cracks a no-invuln Questoris:** Questoris get only a 3+ save in the fight phase (Ion
  Shield is SHOOTING-only), so S10 fists / S8 AP-3 blades / Dev hammers punch straight through —
  ~15-18 per DC+Lemartes charge.
- **Delivery beats screening:** re-roll charge + re-drop means the alpha reliably reaches a Knight
  I failed to fully wall off; a lone Knight exposed to a 9" drop-charge is dead.
- **Force-multipliers:** Lemartes / Priests / Chaplains buff the DC (Lethal + −1 Dmg + charge
  re-rolls) — blank them and the alpha loses a tier.

## Anti-Sister threats
- Same S10/S8-AP-3 melee vaporizes T3 W1 Sv3+ bodies on contact; the re-drop/re-roll delivery
  means the alpha chooses the fight. But it is a MELEE-alpha — it has to LAND before it kills,
  which is exactly the window Sisters' shooting exploits.

## How Imperial Knights fare
- **UNFAVOURABLE ~4/10.** Deciding factor: **melee into the no-melee-invuln fight phase** — the
  one thing Ion Shield can't stop. HEIST: **deny the alpha** (chaff screens + castle, deny the
  9" drop), then **Lancer counter-charge** (the 4++ FULL invuln is the only thing that resists BA
  melee) and **assassinate the multipliers** (Lemartes/Priests/Chaplains → DC drop to S8 and go
  OC0 / lose Lethal+−1Dmg); win on OC. Accept you're the underdog.

## How Adepta Sororitas fare
- **EVEN ~5/10 — BETTER than Knights.** This is the archetype where Sisters' shooting-answer
  beats the Knight's invuln-answer. Deciding factor: **massed AP-1/2 bolter + melta VOLUME +
  Miracle Dice shoots each brick down as it lands** — Sanguinary Guard's −1-to-hit/−1-to-wound is
  **MELEE-only**, so my melta ignores it. **Plan:** Hallowed Martyrs — Overwatch/shoot the drop on
  arrival, tarpit survivors with Arco/Sacresants (waste the charge), let W1 bodies WASTE the DC's
  multi-damage fists, out-score. Kill the enabler characters to strip Red Thirst's buffs.
